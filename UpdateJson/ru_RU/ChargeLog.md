# Version 5.1.4-Beta (97)

# ADD
- [BETA] Добавлена функция анализа хранилища с возможностью указания пользовательского каталога для анализа
- Добавлена адаптация для русского языка

# UPDATE
- Timed теперь не завершается при отсутствии конфигурации при запуске, а переходит в режим ожидания. Параметр date больше не обязателен – он автоматически добавляется программой. Все ключи теперь регистронезависимы
- Улучшена многоподдержка языков в приложении: используются глобальные переменные для динамической замены текста интерфейса, сокращено количество дублирующихся файлов
- Улучшено распознавание узлов F2FS GC для повышения совместимости с большим числом устройств
- Оптимизирована классификация и очистка файлов с параллельной обработкой внутреннего и внешнего хранилища

# FIX
- Исправлена проблема с большим количеством пустых строк в файлах журнала
- Исправлены ошибки проверки пустоты каталогов в некоторых скриптах
