# Version 5.2.1 (101) Release

## ADD

- Анализ хранилища (NCDU) теперь поддерживает отображение типов символических ссылок, оптимизация производительности
- Добавлена очистка журналов сбоев SystemServer
- Добавлен предустановленный набор правил очистки хранилища:
```
com.tencent.mobileqq   #QQ
```

## UPDATE

- Поддержка параллельной классификации/очистки файлов, распределение в зависимости от кратности ядер CPU устройства, измеренная скорость классификации файлов до x2
- Унифицированная упаковка модуля, при установке автоматически распаковывается соответствующая архитектура, не занимает дополнительное пространство
- Оптимизация темы, компоновки и анимации App UI, обновление версий библиотек
- Теперь белый список также действует для очистки системного кэша

## FIX

- Исправлена ошибка, из-за которой файловые операции могли зависать в некоторых сценариях
- Исправлена аномалия анимации в прозрачном режиме App
