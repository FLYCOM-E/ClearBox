# Version 5.2.2 (102) Release

## ADD 

- На странице настроек автоматической очистки теперь отображается время последнего запуска; если очистка никогда не запускалась/не настраивалась, поле остаётся пустым
- Добавлен предустановленный набор правил очистки приложений: WeChat (com.tencent.mm)

## UPDATE

- Переработан экран запуска App в соответствии с рекомендациями; при запуске больше не отображается пользовательский Splash
- Классификация файлов больше не показывает элементы с количеством 0
- Интервал автоматического обновления языка в Timed изменён на 5 минут, исправлена задержка обновления языка
- Оптимизация кода App: удалён неиспользуемый код, обновлён некоторый устаревший код
- Удалена бесполезная нижняя панель Tab в App для улучшения полноэкранного опыта
- Очистка кэша хранилища App больше не сообщает об ошибке при неудаче, поскольку в большинстве случаев причина — отсутствие каталога кэша
- Реорганизация каталогов: файлы белого списка больше не разбросаны по каталогу конфигурации, а находятся в отдельном каталоге
- Белый список теперь применяется к приватным каталогам приложений во внутреннем хранилище — мусор и пустые папки внутри них больше не очищаются
- Очистка по пользовательским правилам теперь отображает общий размер очистки

## FIX

- [Test] Протестировано исправление исчезновения загруженных тем в `Xiaomi Themes` и аномальной загрузки изображений в `TIM`
- Исправлена ошибка, из-за которой строка поиска в интерфейсе выбора App сливалась со строкой состояния
