# Version 5.2.2 (102) Release

## ADD 

- 自動清理設定頁面現在會顯示上次執行時間，如果從未執行/設定過則顯示為空
- 新增軟體清理規則預設: 微信/WeChat (com.tencent.mm)

## UPDATE

- App 啟動畫面改造，遵循相關規範，啟動時不再顯示自訂 Splash
- 現在檔案歸類不再顯示歸類數量為 0 的項目
- Timed 語言自動更新時間改為 5 分鐘，修復語言更新不及時問題
- App 程式碼最佳化，刪除無效程式碼，修改部分老舊程式碼
- 刪除 App 底部無用 Tab 欄，提高全螢幕體驗
- 現在 App 儲存快取清理失敗不再報錯，因為其中大多數僅因快取目錄不存在
- 目錄整理：白名單檔案現在不再散落於設定目錄而是專有目錄內
- 現在白名單對內部儲存 App 私有目錄生效，不會再清理其內垃圾、空資料夾
- 現在自訂規則清理會顯示總清理大小
