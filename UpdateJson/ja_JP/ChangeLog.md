# Version 5.2.2 (102) Release

## ADD 

- 自動クリーン設定ページに前回実行時間が表示されるようになりました。一度も実行/設定されていない場合は空で表示されます
- アプリクリーンルールプリセットを追加: WeChat (com.tencent.mm)

## UPDATE

- App 起動画面を刷新し、関連ガイドラインに準拠。起動時にカスタム Splash を表示しなくなりました
- ファイル分類で件数が 0 の項目を表示しなくなりました
- Timed の言語自動更新間隔を 5 分に変更し、言語更新の遅延問題を修正
- App コード最適化：無効なコードを削除し、一部の古いコードを更新
- App 下部の不要な Tab バーを削除し、全画面表示の体験を向上
- App のストレージキャッシュクリーン失敗時にエラーを報告しなくなりました。失敗のほとんどはキャッシュディレクトリが存在しないことが原因のためです
- ディレクトリ整理：ホワイトリストファイルは設定ディレクトリに散在せず、専用ディレクトリに配置されるようになりました
- ホワイトリストが内部ストレージのアプリプライベートディレクトリに適用され、その中のゴミや空フォルダがクリーンされなくなりました
- カスタムルールクリーンで合計クリーンサイズが表示されるようになりました

## FIX

- [Test] `小米テーマ` でダウンロードしたテーマが消える問題と、`TIM` の画像読み込み異常の修正をテスト
- App 選択画面の検索ボックスがステータスバーに重なるバグを修正
