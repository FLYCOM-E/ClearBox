# Version 5.2.1 (101) Release

## ADD

- ストレージ分析（NCDU）がシンボリックリンクタイプの表示をサポート、パフォーマンス最適化
- SystemServer クラッシュログのクリーニングを追加
- ストレージクリーニングルールプリセットを追加:
```
com.tencent.mobileqq   #QQ
```

## UPDATE

- ファイル分類/クリーニングの並行処理をサポート、デバイスの CPU コア倍数に基づいて割り当て、実測ファイル分類速度最大 x2
- モジュールを統合パッケージ化、インストール時に対応アーキテクチャを自動解凍、追加ストレージ容量を使用しない
- App UI テーマ、レイアウト、アニメーションの最適化、ライブラリバージョンをアップグレード
- ホワイトリストがシステムキャッシュクリーニングにも適用されるようになりました

## FIX

- 一部のシナリオでファイル操作がフリーズする可能性があるバグを修正
- App の透明モードのアニメーション異常を修正
