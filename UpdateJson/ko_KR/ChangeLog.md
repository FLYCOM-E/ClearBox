# Version 5.2.2 (102) Release

## ADD 

- 자동 정리 설정 페이지에 마지막 실행 시간이 표시됩니다. 한 번도 실행/설정하지 않은 경우 비어 있음으로 표시됩니다
- 앱 정리 규칙 사전 설정 추가: WeChat (com.tencent.mm)

## UPDATE

- App 시작 화면 개편, 관련 가이드라인 준수, 시작 시 커스텀 Splash를 더 이상 표시하지 않음
- 파일 분류에서 개수가 0인 항목을 더 이상 표시하지 않음
- Timed 언어 자동 업데이트 간격을 5분으로 변경, 언어 업데이트 지연 문제 수정
- App 코드 최적화: 불필요한 코드 삭제, 일부 오래된 코드 수정
- App 하단의 불필요한 Tab 바를 삭제하여 전체 화면 경험 개선
- App 저장소 캐시 정리 실패 시 더 이상 오류를 보고하지 않음. 실패의 대부분은 캐시 디렉터리가 존재하지 않기 때문임
- 디렉터리 정리: 화이트리스트 파일이 더 이상 구성 디렉터리에 흩어져 있지 않고 전용 디렉터리에 위치함
- 화이트리스트가 내부 저장소의 앱 개인 디렉터리에 적용되어, 그 안의 쓰레기 및 빈 폴더를 더 이상 정리하지 않음
- 커스텀 규칙 정리 시 총 정리 크기가 표시됨
