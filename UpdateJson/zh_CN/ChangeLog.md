# Version 5.2.2 (102) Release

## ADD 

- 自动清理设置页面现在会显示上次运行时间，如果从未运行/设置过则显示为空
- 新增软件清理规则预设: 微信/WeChat (com.tencent.mm)

## UPDATE

- App 启动屏改造，遵循相关规范，启动时不再显示自定义 Splash
- 现在文件归类不再显示归类数量为 0 的项
- Timed 语言自动更新时间改为 5 分钟，修复语言更新不及时问题
- App 代码优化，删除无效代码，修改部分老旧代码
- 删除 App 底部无用 Tab 栏，提高全面屏体验
- 现在 App 储存缓存清理失败不再报错，因为其中大多数仅因缓存目录不存在
- 目录整理：白名单文件现在不再散落于配置目录而是专有目录内
- 现在白名单对内部储存 App 私有目录生效，不会再清理其内垃圾、空文件夹
- 现在自定义规则清理会显示总清理大小
