# Вклад в ClearBox

Спасибо, что готовы помочь! ClearBox — проект, который в основном поддерживается одним человеком (по крайней мере пока :-) ), поэтому любая помощь — даже одна строка конфига — будет оценена разработчиком.
Выберите роль ниже по своим силам. **Первые два направления не требуют написания кода.**



## Способы внести вклад

| Направление | Что делать | Куда это пойдёт |
|---|---|---|
| Конфиги | Пишите и делитесь правилами очистки/сортировки/автоматизации | Встроенные конфиги или коммьюнити-наборы правил |
| Перевод | Улучшайте строки перевода | `.docs/README_*.md` или текст в приложении / TUI |
| Тестирование | Собирайте билд на своём устройстве/ROM и сообщайте о багах | Issues или Telegram-группа |
| Код | Разработка C-ядра, приложения Kr-Script, скриптов сборки | Pull Requests & Push |



### Конфиги (написание и отладка конфигов)

Всё ниже — это чистый текст: если вы умеете редактировать `.txt`, вы уже можете помочь:

Предустановленные конфиги:
- `AppSource/clearbox/src/main/assets/usr/Timed_xml/` — задачи автоматизации
- `FileConfigs/` — правила очистки / сортировки файлов
- `AppConfigs/` — правила приватного хранилища приложений

Пользовательские конфиги:
- `/data/adb/wipe_cache/CleanConfigs` — правила очистки замусоренных каталогов
- `/data/adb/wipe_cache/BindConfigs` — правила перенаправления хранилища

Синтаксис: смотрите описание соответствующих разделов в README. Соблюдайте правила:

- Один PR (или один файл) — одно правило, названное по тому, что оно очищает
- Часть правил использует относительные пути — **не** кодируйте пути, начинающиеся с корня `/xxx`
- Комментарии `#` старайтесь держать на отдельной строке (единственное исключение — инлайновые комментарии `#ext` в конце строки)
- Пожалуйста, тестируйте правила на своём устройстве и указывайте в PR устройство / ROM / версию Android.
- Предустановленные конфиги коммитьте в указанные выше каталоги и **открывайте PR**
- Пользовательские конфиги рекомендуется публиковать в коммьюнити или в Telegram-группе



### Перевод (улучшение строк)

Нашли опечатку, корявое выражение или непереведённую строку? Добро пожаловать с PR.
Старайтесь делать **только один язык за PR**, чтобы ревью было быстрым.
Сейчас в проекте есть следующие языки — выбирайте, какой знаете лучше:
- **`en-US / zh-CN / zh-TW / ru-RU / ko-KR / ja-JP`**
(Как, какого-то не нашли :-)? Ну, тогда придётся попросить вас добавить)



### Тестирование (улучшение функций и баг-репорты)

При сообщении о проблеме укажите:

- Устройство и версию Android:
- ROM (MIUI / HyperOS / AOSP...)
- Root-схему: Magisk / APatch / KernelSU + версию
- Версию ClearBox (Version Code)
- Файловую систему (если знаете): f2fs / ext4 / sdcardfs
- Что произошло на самом деле vs ожидаемое поведение
- Вывод терминала или логи (если есть)



### Код (добавление функций / исправление багов)

- Настройте **NDK** и задайте переменную окружения **ANDROID_NDK_HOME** как путь к корню **NDK**
- Если вы глубоко участвуете в разработке и отладке **App**, настройте окружение **Android SDK**
- Вот несколько базовых настроек окружения:

Базовые пакеты

``` shell
# Debian, Ubuntu
sudo apt install zip make build-essential

# Arch
sudo pacman -S zip make base-devel

# Alpine
sudo apk add zip make build-base

# Fedora
sudo dnf install zip make
sudo dnf groupinstall "Development Tools"
```

Клонируйте проект (только для справки — если делаете PR, форкайте сами)

``` shell
git clone https://github.com/FLYCOM-E/ClearBox
cd ClearBox/ && chmod +x *

export TARGET_API=23         # можно подстроить целевую версию API под свои нужды
export TARGET_ABI=aarch64   # на выбор: aarch64, armv7a, x86_64, riscv64
```

Сборка ядра

``` shell
./build.sh       # для сборки APK: --build-apk
```

Стиль коммитов: придерживайтесь текущего стиля: `Fix: ...` / `Update: ...` / `Add: ...`; старайтесь, чтобы каждый коммит делал одно связанное изменение; если изменений несколько, разделяйте их переводом строки.
Требования к PR: один PR = одна функция или одно исправление. Опишите, что вы изменили и **почему** (если нужно. Лучшее «почему» — реальный кейс сбоя, с которым вы столкнулись).



## 🚫 Пожалуйста, не надо

- Не открывайте issue вида «не работает» без указанной выше информации об устройстве — без неё мейнтейнер может вообще не суметь воспроизвести проблему
- Идеи фич: прежде чем писать много кода, создайте Issue и обсудите, чтобы не тратить время впустую
- Не смешивайте правки форматирования и изменения логики в одном коммите
- Не коммитьте непротестированные «правила-догадки» с регулярками
